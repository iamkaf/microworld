# Security policy

Please use GitHub's private reporting flow for anything that may affect the confidentiality, integrity, or availability of Microworld. Open a [private vulnerability report](https://github.com/iamkaf/microworld/security/advisories/new) with the affected version, impact, reproduction steps, and any suggested mitigation. Do not open a public issue for a suspected vulnerability.

Use [GitHub Issues](https://github.com/iamkaf/microworld/issues) for reproducible non-security bugs, support, setup questions, and ideas.

Security fixes target the latest commit on the default branch. No released version has a separate maintenance window yet.
